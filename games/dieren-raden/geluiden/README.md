# Geluiden

De dierengeluiden staan in `manifest.json` (Nederlandse diernaam -> lijst bestanden). Per tik wordt er willekeurig één van het dier gekozen. Opnames langer dan 3,5 seconde worden uitgefaded.

Nieuw geluid toevoegen: zet de mp3 in deze map en voeg de bestandsnaam toe aan de lijst van het dier in `manifest.json`. Een dier zonder bestanden maakt geen geluid.

Dier-namen: paard, kikker, poes, hond, vogeltje, koe, varken, geit, olifant, kip, slang, leeuw, aap.
